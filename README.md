# เหลือเก็บ (LueaKeb)

แอปช่วยแบ่งเงินเดือนหรือรายรับตามสูตร **50/30/20** กรอกจำนวนเงินแล้วเห็นสัดส่วนค่าใช้จ่ายและเงินออมทันที พัฒนาด้วย Expo และ React Native พร้อมหน้าจอภาษาไทยที่ปรับการจัดวางตามขนาดจอ

## ฟีเจอร์

- คำนวณทันทีเมื่อเปลี่ยนรายรับ โดยเริ่มต้นที่ 5,000 บาท
- แบ่งเงินเป็นค่าใช้จ่ายจำเป็น 50% ความต้องการส่วนตัว 30% และเงินออมและลงทุน 20%
- แสดงจำนวนเงินรูปแบบไทยพร้อมทศนิยมไม่เกิน 2 ตำแหน่ง
- แสดงการ์ดแนวตั้งเมื่อหน้าจอกว้างน้อยกว่า 700 และเรียงแนวนอนบนจอใหญ่
- รองรับพื้นที่ปลอดภัยของหน้าจอและการเลื่อนหน้าเมื่อกรอกข้อมูล

## ตัวอย่างการคำนวณ

สำหรับรายรับ **5,000 บาท**:

| หมวด | สัดส่วน | จำนวนเงิน |
| --- | --- | --- |
| ค่าใช้จ่ายจำเป็น | 50% | 2,500 บาท |
| ความต้องการส่วนตัว | 30% | 1,500 บาท |
| เงินออมและลงทุน | 20% | 1,000 บาท |

## เริ่มต้นใช้งาน

ต้องมี Node.js และ npm โดย Expo SDK 57 ต้องการ Node.js ขั้นต่ำ 22.13.x ตาม[เอกสาร Expo v57](https://docs.expo.dev/versions/v57.0.0/)

รันคำสั่งต่อไปนี้จากโฟลเดอร์โปรเจกต์:

```bash
npm ci
npm start
```

เลือกเปิดแอปจากเมนูใน terminal หรือใช้คำสั่งตามแพลตฟอร์ม:

| คำสั่ง | การทำงาน |
| --- | --- |
| `npm run web` | เปิดแอปบนเว็บเบราว์เซอร์ |
| `npm run android` | เริ่ม Expo และเปิดแอปบน Android ที่ตั้งค่าไว้ |
| `npm run ios` | เริ่ม Expo และเปิด iOS Simulator บน macOS ที่ติดตั้ง Xcode |

การทดสอบบนมือถือจริงต้องใช้ Expo Go ที่รองรับ SDK ของโปรเจกต์ หรือ development build ที่ตรงกับโปรเจกต์

## การใช้งาน

1. กรอกเงินเดือนหรือรายรับในช่องจำนวนเงิน โดยใช้ตัวเลขและจุดทศนิยม เช่น `25000` หรือ `25000.50`
2. ดูยอดแบ่งเงินทั้งสามหมวดซึ่งอัปเดตอัตโนมัติ
3. ดูยอดรายรับรวมด้านล่าง และเปลี่ยนจำนวนเงินเพื่อทดลองวางแผนใหม่

ข้อมูลอยู่ในหน่วยความจำของหน้าจอเท่านั้น ยังไม่มีการบันทึกรายรับ ประวัติ ฐานข้อมูล หรือระบบบัญชีผู้ใช้ เมื่อเปิดหน้าจอใหม่จะเริ่มที่ค่าเริ่มต้น

ช่องว่าง ค่าติดลบ และค่าที่ไม่ใช่ตัวเลขที่รองรับจะคำนวณเป็น 0 สัดส่วนยังคงเป็น 50/30/20 และแต่ละหมวดปัดเศษเพื่อแสดงผลแยกกัน จึงอาจมีส่วนต่างระดับสตางค์เมื่อรวมยอดที่แสดง

## โครงสร้างโปรเจกต์

```text
src/
  app/
    _layout.tsx       # กำหนด Stack และแถบสถานะ
    index.tsx         # หน้าคำนวณหลัก สูตรแบ่งเงิน และสไตล์
    explore.tsx       # หน้าตัวอย่างที่เหลือจาก Expo starter
  components/        # คอมโพเนนต์จาก starter
  constants/         # ค่าธีมจาก starter
  hooks/             # hooks สำหรับธีม
  global.css         # ตัวแปรฟอนต์สำหรับเว็บ
assets/              # ไอคอนและรูปภาพ
scripts/             # สคริปต์จาก starter
app.json             # ตั้งค่าแอปและ Expo plugins
package.json         # dependencies และคำสั่ง npm
```

หน้าคำนวณปัจจุบันใช้คอมโพเนนต์ React Native และสไตล์ภายใน `src/app/index.tsx` โดยตรง ส่วนแท็บและคอมโพเนนต์ตัวอย่างบางส่วนยังอยู่ในโปรเจกต์ แต่ไม่ได้ใช้เป็นหน้าหลัก

## ตรวจสอบและสร้างเว็บ

ตรวจ TypeScript:

```bash
npx tsc --noEmit
```

สร้างไฟล์เว็บแบบ static ไปยังโฟลเดอร์ `dist/`:

```bash
npx expo export --platform web --output-dir dist
```

คำสั่งนี้สร้างไฟล์สำหรับนำไปโฮสต์ ยังไม่ได้เผยแพร่เว็บโดยอัตโนมัติ
